FAQ

Good to know

Will I lose my configuration when upgrading from 1.x?

No. The data path is unchanged, so platforms, covers and playtime carry over automatically.

What are the system requirements?

Windows 10 or 11 with WebView2 (the installer handles it). On Linux you need a GTK3 desktop and webkit2gtk 4.1 — the .deb package pulls those in for you.

Do I need a gamepad to use it?

Not at all. Everything works with a keyboard and mouse; the controller layout is there for couch play.

Where do the covers come from?

SteamGridDB provides automatic artwork. You can also set a custom local file or image URL for any game.

Is it really free?

Yes — MIT licensed and free to use. If you want to support development, there is a Ko-fi link in the footer.

Can I run it from a USB stick?

Yes. Use the AppImage together with portable mode and the launcher keeps its config next to the executable.
