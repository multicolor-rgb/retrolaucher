For the couch

Set each platform up once. After that the pad is enough.

Controller
Left and right move the shelf. Up opens platforms. LB / RB switch system, LT / RT change the shelf mode. A plays, Y opens details, B goes back, Start opens settings.
Keyboard
Arrows and Enter. A letter jumps to that title. R picks a random game, F toggles a favourite, F11 toggles fullscreen.
Attract mode
After two minutes idle the shelf keeps moving. Any key, click or pad input stops it. Turn it off in Settings.
Nine shelves
Flat, arc, Big Picture, cascade, grid, list with description, spotlight, fullscreen covers, platform frame. Eleven cover ratios, or your own.

For the library

The part you do at the desk, so the couch stays simple.

Platforms
Thirty presets fill extensions, colour, cover ratio and scraper ids. Each system has its own ROM folder, emulator and arguments. Rename later — the id stays, so covers and stats stay.
Artwork
SteamGridDB, RAWG, ScreenScraper.fr and TheGamesDB, in Polish and English when the source has both. A file or a URL overrides them. Missing art gets an offline placeholder.
Playtime
Hours, launch count, last played, favourites, sort, and a library check for missing folders, empty files and duplicates.
USB stick
Portable mode copies config, stats and covers into LauncherData beside the app. ROM paths are stored relative to the stick and expand to whatever letter it gets.
PC games
.exe, .AppImage and .sh. On Linux: Wine, Wine-GE or Proton-GE, with a one-click download of the runner. Prefix and environment can be set per game.
Import
EmulationStation gamelist.xml, plus a JSON backup of config and stats. Test the emulator command from Settings before you sit down.

Before you install

Will I lose my configuration when upgrading from 1.x?

No. The data path is unchanged, so platforms, covers and playtime carry over.

What are the system requirements?

Windows 10 or 11 with WebView2 — the installer fetches it if needed. On Linux, a GTK3 desktop and webkit2gtk 4.1. The .deb pulls those in.

Do I need a gamepad?

No. Keyboard and mouse cover everything. The pad layout is there for the couch.

Where do the covers come from?

SteamGridDB, RAWG, ScreenScraper.fr and TheGamesDB, if you add the keys. You can also set a local file or an image URL per game.

Is it really free?

Yes. MIT licensed. There is a BuyCoffeeTo link in the footer if you want to support the work.

Can I run it from a USB stick?

Yes. AppImage plus portable mode keeps config, stats and covers next to the executable. Emulators stay installed on the machine.
