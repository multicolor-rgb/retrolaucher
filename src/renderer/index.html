Dodawanie platformy

Dodaj nazwę platformy, rozszerzenia ROM-ów, kolor i typ okładki. Launcher sam utworzy wpis konfiguracji.

Szybka wskazówka: po dodaniu platformy ustaw folder ROM-ów, polecenie emulatora i opcjonalne argumenty startowe.

ROM-y i emulatory

Każda platforma może mieć własny folder ROM-ów, emulator, argumenty i proporcje okładek.

Windows

Dla emulatora wybierz plik `.exe`, a dla ROM-ów folder z grami. Lokalne pliki okładek mogą wymagać poprawnego adresu `file:///`, szczególnie dla ścieżek dyskowych typu `C:\...`.

Przykład emulatora: C:\Emulatory\PPSSPP\PPSSPPWindows64.exe
Przykład okładki: file:///C:/Retro/covers/god-of-war.jpg

Linux

Na Linuxie zwykle wybierasz binarkę emulatora albo komendę uruchomieniową, a przy Flatpaku mogą być potrzebne uprawnienia do katalogów spoza sandboxa, np. `/media` lub własnych folderów z ROM-ami.

Przykład emulatora: /usr/bin/retroarch
Przykład Flatpak: flatpak run org.ppsspp.PPSSPP
Przykład uprawnień: flatpak override --user --filesystem=/media org.ppsspp.PPSSPP

Jak dodać platformę i okładki

1. Dodaj platformę w zakładce „Platformy”. 2. Ustaw folder ROM-ów i emulator. 3. W zakładce „Okładki” wybierz platformę i pobierz dane albo ustaw ręczną okładkę przez URL lub plik lokalny.

Jeśli lokalna okładka nie pokazuje się poprawnie, sprawdź format ścieżki `file://` oraz to, czy aplikacja ma dostęp do pliku.
