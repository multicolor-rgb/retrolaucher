Źródła metadanych i okładek

Skonfiguruj klucze API dla poszczególnych scraperów. SteamGridDB i RAWG działają najlepiej dla nowszych gier, ScreenScraper i TheGamesDB są zorientowane na retro (SNES, Genesis, arcade, handheldy). Możesz skonfigurować tylko te źródła, z których chcesz korzystać — pozostałe zostaną pominięte przy pobieraniu.

SteamGridDB

Wpisz własny klucz API, aby pobierać okładki automatycznie. Klucz generujesz na steamgriddb.com w ustawieniach konta.

RAWG

Klucz API RAWG służy do pobierania opisów, gatunków i oceny Metacritic. Klucz generujesz bezpłatnie na rawg.io/apidocs.

ScreenScraper.fr

Główne źródło metadanych dla retro (opisy, gatunki, liczba graczy, okładki). Wymaga darmowego konta zarejestrowanego na screenscraper.fr — podaj tu login i hasło konta (nie klucz API).

TheGamesDB

Zapasowe źródło okładek dla niszowych ROM-ów, gdy SteamGridDB i ScreenScraper nie znajdą trafienia. Wymaga darmowego klucza API z thegamesdb.net.

Windows

Dla emulatora wybierz plik `.exe`, a dla ROM-ów folder z grami. Lokalne pliki okładek mogą wymagać poprawnego adresu `file:///`, szczególnie dla ścieżek dyskowych typu `C:\...`.

Przykład emulatora: C:\Emulatory\PPSSPP\PPSSPPWindows64.exe
Przykład okładki: file:///C:/Retro/covers/god-of-war.jpg

Linux

Na Linuxie zwykle wybierasz binarkę emulatora albo komendę uruchomieniową, a przy Flatpaku mogą być potrzebne uprawnienia do katalogów spoza sandboxa, np. `/media` lub własnych folderów z ROM-ami.

Przykład emulatora: /usr/bin/retroarch
Przykład Flatpak: flatpak run org.ppsspp.PPSSPP
Przykład uprawnień: flatpak override --user --filesystem=/media org.ppsspp.PPSSPP

Jak dodać platformę i okładki

1. Dodaj platformę w zakładce „Platformy”. 2. Ustaw folder ROM-ów i emulator. 3. W zakładce „Okładki” wybierz platformę i pobierz dane albo ustaw ręczną okładkę przez URL lub plik lokalny.

Jeśli lokalna okładka nie pokazuje się poprawnie, sprawdź format ścieżki `file://` oraz to, czy aplikacja ma dostęp do pliku.

Skrót zatrzymywania emulatora

Aby zamknąć aktywny emulator, naciśnij jednocześnie L3 + R3 + LB + RB na padzie.

Klawisze: L3 + R3 + LB + RB
